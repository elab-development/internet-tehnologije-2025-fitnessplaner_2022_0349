# Fitness aplikacija

## Opis
Web aplikacija za upravljanje fitnes treninzima.
Backend je razvijen u Laravel-u, a frontend koristi Vite.
Podaci se čuvaju u MySQL bazi.

## Tehnologije
- Laravel (PHP)
- Vite (JavaScript)
- MySQL

## Pokretanje aplikacije

1. Instalacija zavisnosti:
   composer install
   npm install

2. Pokretanje backend servera:
   php artisan serve

3. Pokretanje frontend dela:
   npm run dev

Backend je dostupan na:
http://localhost:8000
